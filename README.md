Estudos de Python 🐍

Este repositório foi criado para armazenar e organizar os conteúdos, exercícios e códigos desenvolvidos durante as aulas de Python na plataforma Alura.

📚 Conteúdo

Aqui serão armazenados os conhecimentos adquiridos ao longo dos cursos, incluindo temas como:

Fundamentos de Python
Variáveis e tipos de dados
Estruturas condicionais
Estruturas de repetição
Funções
Listas, tuplas e dicionários
Programação Orientada a Objetos (POO)
Classes, objetos, herança e polimorfismo
Entre outros conceitos da linguagem

🎯 Objetivo
O objetivo deste repositório é servir como um espaço de estudo, prática e consulta, registrando minha evolução no aprendizado de Python através dos cursos da Alura.
Este é um repositório de estudos e pode conter códigos e exercícios desenvolvidos durante o processo de aprendizagem.
